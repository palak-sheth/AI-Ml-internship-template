LLM(large language model)

    -A llm is an AI model which understand and genrates human like text.
    -It is trained on a very large amount of text data such as books, articles, websites and codes.
    -Examples of LLM includes chat GPT, Gemini, LLaMA.

how does an llm works?

    -LLM works by predicating the next word or token based on the input text or previous context.
    -So they do not "thinks" like human; instead, they uses probability to choose the most suitable next token.

TOKENS

    -LLM breaks text into small unit called tokens.
    -Tokens can be:
        1. A full word.
        2. A part of the word.
        3. Symbol or punctuation.
    -Example:"Machine learning" → ["Machine", " learning"]
    -Tokens help the model process text efficiently.

CONTEXT

    -Context refers to the information provided earlier in the conversation or input.
    -LLMs use context to understand what the user is talking about and generate relevant responses.
    -Example: If a user mentions their name earlier, the model can remember and use it later within the same conversation.

TEMPERATURE

   -Temperature controls the randomness and creativity of the output.
   -Low temperature → factual and accurate responses
   -High temperature → creative and diverse responses

Applications of LLMs

   -Chatbots and virtual assistants
   -Code generation and debugging
   -Text summarization and translation

SUMMARY

   -LLMs generate human-like text by predicting the next token using context and probability.
